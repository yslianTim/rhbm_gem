# Archived FirstStage evidence

The study infrastructure and large JSON ledgers are retired. Scientific evidence is preserved in immutable Git history at [`503a6607674e068e4d3ef3db52aa770abcf3aea4`](https://github.com/yslianTim/rhbm_gem/tree/503a6607674e068e4d3ef3db52aa770abcf3aea4/docs/research/first-stage-sampling). This index records every JSON present before cleanup; `git show COMMIT:path > /tmp/name.json` recovers exact bytes without switching branches or restoring research switches to production. Original study source/runners are in the same commit under tests/research and tests/support. Real-data inputs remain external; their source hashes are recorded in these ledgers. Ignored detailed build outputs are supplemental and are not claimed as a durable archive.

Only necessary production references now live in `tests/fixtures/joint_component/first_stage.json`. Ordinary builds/tests/documents do not read these archived ledgers. Tables in the three reports keep their original numbers. Historical statements that tooling was retained describe the original delivery, superseded by this cleanup.
